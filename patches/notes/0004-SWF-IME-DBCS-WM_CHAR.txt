mcs/class/System.Windows.Forms/System.Windows.Forms/NativeWindow.cs:
combine DBCS lead/trail bytes from WM_CHAR into one Unicode character.

Win98 delivers IME-committed text to ANSI windows as one WM_CHAR per byte
of the DBCS character.  Mono appended each byte as if it were a Unicode
code point, so typing "你好" showed "ÄãºÃ" (mojibake).

NativeWindow.WndProc now pairs lead/trail bytes on Win9x (OS major < 5),
decodes them with Encoding.GetEncoding(GetACP()) and re-dispatches a single
WM_CHAR carrying the Unicode character.  Non-DBCS characters (ASCII) pass
through unchanged.

Requires k32x.dll export IsDBCSLeadByteEx (added) and I18N.CJK.dll for
code page 936.
