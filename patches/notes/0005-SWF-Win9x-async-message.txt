Control.Invoke/BeginInvoke queue an AsyncMethodData by posting WM_USER+3
(WM_ASYNC_MESSAGE, 0x0403) to Mono's foster window.  Windows 98's user32
rewrites that message number to 0x173 when GetMessageA returns it, so the
case for 0x403 never matched: the async method was never executed and
Control.Invoke blocked forever (BeginInvoke silently did nothing).
